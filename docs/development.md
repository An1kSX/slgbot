# Разработка

Рабочая версия Python для контейнера — 3.11. Выполняйте команды из корня проекта.

```bash
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements/dev.txt
python -m pytest -q
```

В Windows активация: `.\.venv\Scripts\Activate.ps1`.
Если системная временная папка недоступна, задайте новый каталог внутри проекта:
`python -m pytest -q --basetemp=.pytest_cache/local-run`.
Pytest очищает каталог, указанный в `--basetemp`; используйте его только для тестов.

Тесты не обращаются к Telegram, OpenAI и MySQL. Проверяются логика обращений,
настройки, HTML/JSON, разделение чатов и дней, состав ZIP и архивация.
Проверки файлов Docker не заменяют реальную сборку контейнеров.

Точка входа: `python -m slgbot`. Прямой запуск отдельных `.py` не поддерживается.
Для запуска вне Docker заполните `.env`, обеспечьте отдельную MySQL и добавьте
`MYSQL_HOST=127.0.0.1`, `MYSQL_PORT=3306`. Compose не публикует MySQL на хост.
Локальный запуск подключается к настоящим внешним сервисам.

Код находится в пакете `slgbot`, внутренние импорты используют его имя.
HTML-ресурсы находятся в `slgbot/templates` и по умолчанию разрешаются относительно
пакета. Docker копирует только пакет и runtime-зависимости; секреты, тесты и
данные не входят в образ. Исторические планы в `docs/superpowers` описывают старую
структуру и не являются инструкцией по развёртыванию.
